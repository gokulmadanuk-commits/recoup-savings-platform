## Document types

Per vendor: 1 contract + 12-15 monthly invoices spanning the contract term, so YoY escalation findings show a visible jump at the renewal-month boundary. Total ~22 vendors x ~13-16 docs = ~310-350 documents. Mix formats deliberately to exercise the parser: contracts as PDF (SaaS Order Forms, insurance declarations pages, leases) AND Word .docx (services/janitorial/agency/professional); invoices as PDF for most vendors and Excel .xlsx for line-heavy categories (cloud, telecom, utilities). Generate PDFs tagged (PDFKit >= 0.15.0, real ToUnicode map, Table/TR/TH/TD structure, embedded subsettable fonts) so getTextContent extraction round-trips. Universal invoice anatomy: invoice # (VND-YYYY-NNNN), invoice date, due date, PO # (PO-NW-NNNN), bill-to (Northwind AP), remit-to + EIN, billing period, line-item table (description/qty/unit price/line total), subtotal, tax (~7-9% where applicable), total, payment terms (Net 15/30/45), remittance. Contracts carry the universal header (parties, effective/commencement date, initial term, auto-renewal clause with explicit notice window, governing law, signature block) plus category-specific bodies (rate card / Order Form, escalation clause, term/renewal, SLA, key quantities).
